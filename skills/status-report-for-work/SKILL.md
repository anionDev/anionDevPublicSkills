# Skill status-report-for-work

Print a short status report for the current work. The status report should contain the following information:

Is there anything left to do? If yes:
- What is the current task which is worked on?
- What is the current progress of the task?
- What is the next step to do?

Is there any background task which is still running? If yes:
- What is the background task?
